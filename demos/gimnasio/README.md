# Demo: Santiago GYM

En vivo: **https://santiago3336.github.io/demos/gimnasio/**

> [!WARNING]
> «Santiago GYM» es una **marca inventada** para mostrar el diseño. Los precios, horarios y sedes son de ejemplo.

## Qué demuestra

Es un sitio de **planes y reservas** para un gimnasio con varias sedes:

- Hero de cartel con un amanecer sobre los cerros y una línea de pulso que subraya el titular.
- Planes con precio a la vista y una barra que muestra cuánto cuesta cada plan por mes.
- Horario de clases por día, con cupos, que abre en el día de hoy (hora de Bogotá). Cada clase tiene un botón para reservarla directamente.
- Sedes con su dirección, horario, mapa ilustrativo y estado "Abierto ahora" o "Cerrado".
- Reserva de una clase de prueba gratis: el visitante elige sede, día y clase, y la página arma el mensaje de reserva listo para enviar por WhatsApp.

Todo está en un solo `index.html`, sin frameworks ni dependencias.
